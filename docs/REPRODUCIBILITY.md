# Reproduction and asset status

The public stage contains reviewed documentation and aggregate results. The complete scientific source, frozen configurations, fitted model banks, physical patch witnesses, prediction arrays, input rosters, logs and proof payloads remain preserved in the saved project archives.

Automatic approval review blocked the bulk publication because the exact archive payload can include models and individual records. Explicit public-disclosure approval is required before that complete payload can be published. The repository therefore labels the full experiment release as pending.

## Integrity of the public stage

From the repository root, run

    python3 tools/check_publication.py

PUBLICATION_MANIFEST.json identifies every reviewed public file by its size and SHA-256. This command checks those bytes without model fitting, data acquisition or target scoring.

## Complete scientific reproduction

Each study retains its original execution layout and environment requirements. The full release must restore the archived inputs, models, code and configurations under that layout, verify its checksums and use the entry points recorded in its original protocol.

- ACSIncome v20 and RA1 retain separate frozen families, targets and confirmatory claims.
- Adult R13 includes the exact matched-cost parent and its embedded auditability archive.
- MEPS retains the original P88 candidate alongside new-family repeatability, proof continuation and separate roster/population evaluations.
- HMDA V7 requires its exact V2–V6 base chain, and original A remains separate from corrected B.

A source verification, model-parity check, cost certificate, roster decision and population decision have different coverage. The published result ledgers state those scopes. An opened target remains exposed for future confirmation. Preserve unsuccessful cases and unresolved searches in their original denominators.

The full archive registry and publication-content review have been prepared. Some historical dependencies still require restoration and checksum pinning before a complete public asset release can be declared.
