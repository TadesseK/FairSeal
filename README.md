# FairSeal-C

FairSeal-C studies how adding unchanged records from a reserve can protect every qualifying predictor in a frozen model family while preserving native utility and useful model choice.

This repository brings together the ACSIncome, Adult, MEPS and HMDA experiments, including source code, frozen configurations, verification receipts, physical patch witnesses and recorded unsuccessful outcomes. Dataset-specific evidence distinguishes construction, algorithmic repeatability, cost proofs, roster transfer and population inference.

The publication is being organized from the saved, checksum-verified experiment archives. Complete experiment assets and result packages accompany the browsable source and evidence.
